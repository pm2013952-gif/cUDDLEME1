jQuery

jQuery es una librería de JavaScript lanzada en 2006. Nació porque los navegadores de esa época interpretaban el JavaScript de formas distintas, y escribir código que funcionara en todos era difícil. jQuery ofrecía una manera corta y uniforme de hacerlo, con el lema de escribir menos y hacer más.

Sintaxis básica

El símbolo $ es la función principal de jQuery. El patrón siempre es el mismo: seleccionar un elemento y aplicarle una acción.

$('selector').accion();

$('#mensaje').text('Te quiero mucho');   // selecciona por id y cambia el texto
$('.tarjeta').hide();                   // selecciona por clase y oculta

Para usarla hay que cargar el archivo de jQuery antes de tu código, por ejemplo desde un CDN:

<script src="https://cdnjs.cloudflare.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>

Ventajas y desventajas frente a JavaScript moderno

Ventajas

  • Sintaxis corta y fácil de leer.
  • Efectos y animaciones listos para usar.
  • Hay mucho código y plugins existentes, por eso aún aparece en proyectos antiguos.

Desventajas

  • Es una descarga extra que hace la página más pesada.
  • Casi todo lo que resolvía ya existe en JavaScript moderno (querySelector, classList, fetch).
  • Los frameworks actuales usan otro enfoque y no dependen de jQuery.

Efectos típicos

Dos efectos clásicos de jQuery: fadeIn (aparecer poco a poco) y slideToggle (abrir y cerrar deslizando). Pruébalos:

$('#btn-fade').on('click', function () {
  $('#caja').hide().fadeIn(600);        // el mensaje aparece suavemente
});
$('#btn-slide').on('click', function () {
  $('#panel').slideToggle(400);         // la lista se desliza abierta o cerrada
});
